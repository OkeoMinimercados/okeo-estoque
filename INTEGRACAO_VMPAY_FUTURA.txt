OKEO V3.8 — ESTRUTURA API-READY

O APP NÃO CHAMA O VMPAY DIRETAMENTE.
O GitHub Pages é público e não deve conter token/API key.

ARQUITETURA FUTURA:
VMPay API -> Backend seguro -> Formato interno OKEO -> App OKEO

O backend deverá normalizar a API externa para:
1. sync_master
   Retorna products[] e units[].
2. sync_sales
   Retorna sales[] no formato interno do OKEO.
3. sync_stock
   Retorna stock[].
4. status
   Retorna {"ok": true}.

- inventário;

- demais módulos.

SEGURANÇA
