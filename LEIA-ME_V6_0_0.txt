POLÍTICA DE DADOS
Administrador define:
- retenção de vendas detalhadas
- retenção de movimentações
- retenção de diagnósticos
- histórico mensal ou trimestral

Antes de excluir:
1. Sistema simula quantidade de registros.
2. Visões materializadas são reconstruídas.
3. Só depois os dados brutos antigos são removidos.
4. Histórico financeiro/gerencial continua disponível pelos agregados.
