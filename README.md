# OKEO Core V3.23 — Produção

Use frontend e Apps Script V3.23 juntos. Execute `setupOkeoCoreV323`, atualize a implantação `/exec`, confirme `version: 3.23.0` e `authContract: OKEO_AUTH_V1`, publique o frontend e faça Ctrl+F5.

A Base Mestre é o catálogo único. Em Produtos existem apenas Cadastro de Produtos Novos e Planograma por Condomínio/CD. O Planograma pode ser editado por condomínio, por produto ou por importação XLSX/CSV/JSON. A Contagem de Estoque Física usa o Planograma da unidade.
